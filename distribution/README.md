# Directory manifests

Copies of the files used to list the httpfy MCP server in third-party catalogs. Each subfolder mirrors what that catalog expects.

| Folder | Catalog |
|---|---|
| `docker-mcp-catalog/` | Docker MCP Catalog (`servers/httpfy/` in docker/mcp-registry) |
| `devin-marketplace/` | Devin marketplace (`plugins/httpfy/` in CognitionAI/devin-marketplace) |
| `raycast-mcp-registry/` | Raycast Model Context Protocol Registry extension (`OFFICIAL_ENTRIES`, kept as markdown) |

Server endpoint: `https://httpfy.io/mcp` · Registry name: `io.httpfy/httpfy` · Docs: https://httpfy.io/agents
